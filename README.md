##  什么是 Sneko

**Sneko**）是一门**中文拼音编程语言**，
让你用 `shu` `chu` `ruo` 这样的拼音关键字写代码，
一键生成 **HTML / PHP / Python**。

-  **中文拼音** — 一看就懂，零门槛
-  **全默认值** — 不填也能跑
-  **单文件** — 一个 `.sneko` 生成一个目标
-  **三目标** — HTML / PHP / Python
-  **零配置** — 本地运行，无需联网
